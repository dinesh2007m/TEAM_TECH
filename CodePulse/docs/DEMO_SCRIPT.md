# 2–3 minute demo script

## 0:00–0:20 — Introduce the problem
“This is CodePulse, our Coding Practice Progress Coach. It analyses observed solved-problem evidence, finds weak topics, and prepares a focused plan for next week. It does not guess private data or save a plan without human approval.”

## 0:20–0:50 — Run synthetic demo
Select Synthetic demo snapshot, set weekly hours and target companies, then click Run weekly coach. State clearly that the fixture is synthetic. Point out the unique solved count, Graphs count, ranked topics, problem links, and spoken briefing. Click Play voice.

## 0:50–1:10 — Show human approval
Review two or three items in the proposed list. Click Approve & save plan and confirm. Explain that the save is a separate action after the person reviews the list. Run verification and point out the snapshot-only label.

## 1:10–2:00 — Run official cases
Click Run all 4 tests. Show:
- TC1: Graphs is prioritised when the observed graph count is zero.
- TC2: a private profile requests an export and generates no guessed plan.
- TC3: duplicate canonical IDs across platforms count once.
- TC4: an unchanged solved-ID set produces no progress claim.
Open the evidence panel for at least one case.

## 2:00–2:30 — Explain live source and close
Optionally select Public Codeforces profile and enter a permitted public handle. Run the coach, show the source URL and retrieval time, and click verification to refresh counts. If the service is unavailable, show the error state rather than describing the sample as live data.

Close with: “CodePulse combines a deterministic decision policy, explicit human approval, and a separate verification step. The official scenarios are automated and repeatable.”
